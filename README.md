#  Analisis_tiendas

# 🏪 Proyecto de Ventas y Rentabilidad

## 📘 Descripción del Proyecto
Este proyecto tiene como objetivo analizar el rendimiento de cuatro tiendas con base en distintos factores clave de negocio, como ingresos, ventas por categoría, calificaciones de clientes y costos de envío.  
El propósito final es identificar **la tienda más rentable y confiable para realizar inversiones o establecer alianzas comerciales.**

## 📊 Datos Analizados
El análisis incluye las siguientes métricas:
- 💰 **Ingresos totales por tienda**  
- 📦 **Categorías de productos más y menos vendidas**  
- ⭐ **Calificación promedio de los clientes**  
- 🧾 **Productos más y menos vendidos**  
- 🚚 **Costo de envío promedio**

## 🧠 Herramientas Utilizadas
- Python 🐍  
- Pandas (análisis de datos)  
- Matplotlib / Seaborn (visualización)  
- Google Colab (entorno de ejecución)  

## 📈 Resultados Principales
- **Tienda 2** obtuvo los ingresos más altos ($1,116,343,500)  
- **Tienda 3** presentó la mejor calificación promedio (4.05)  
- Las categorías más vendidas corresponden a productos electrónicos y de consumo diario  
- Los costos de envío más bajos se observaron en Tienda 1 y Tienda 4  

## 🧾 Conclusión
Tras analizar todos los factores, se recomienda al Sr. Juan establecer su negocio con **Tienda 2**, ya que presenta **mayores ingresos, buena rotación de productos y satisfacción del cliente**, manteniendo costos de envío competitivos.  
Esto la convierte en la opción más equilibrada y rentable para asociarse o invertir.
